Security with Keycloak SSO

Authentication and authorization for a public-sector platform, handled centrally instead of in every service.

User opens the app and is redirected to Keycloak
Single sign-on: one login across services
Keycloak issues a signed token with the user’s roles
Spring Boot service validates the token on each request
RBAC decides what each role can access

Generic OIDC SSO flow shown for illustration. At NSWS I own the access-management and profile-management microservices that work with this model.

API code

A secured Spring Boot REST endpoint, the style of service I build.

ProfileController.java
@RestController
@RequestMapping("/api/profile")
public class ProfileController {

  private final ProfileService service;

  @GetMapping("/{id}")
  @PreAuthorize("hasRole('USER')")   // RBAC from Keycloak roles
  public ResponseEntity<ProfileDto> get(@PathVariable Long id,
                                        @AuthenticationPrincipal Jwt jwt) {
    return ResponseEntity.ok(service.getProfile(id, jwt.getSubject()));
  }
}

# application.yml: validate tokens issued by Keycloak
spring.security.oauth2.resourceserver.jwt.issuer-uri: https://<keycloak-host>/realms/<realm>
